# Assumptions

Generated by `make assumptions` from config/*.yaml. Edit the config notes, not this page.

Every model input is either sourced, with the document it was read from, or a placeholder: a value not read from a cited source, kept visible until something better replaces it. There are 31 placeholders and 23 sourced values.

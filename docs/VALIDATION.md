# Validation

Generated by `make validate` on 2026-10-20 from the local database. It tests what public data can test and says what it cannot. There is no accuracy number for value per block: revenue values are simulated, gross, before the host share, and unvalidated.

## Size-only baseline

The earlier public prototype (github.com/thutch17/powertown-hackathon), credited as prior work, ranked sites by building size and town permit history; outside Boston, Cambridge and Somerville the permit part is a constant, so in the pilot towns it is a size-only ranking. Here: the 50 candidate sites per region with the most building area, against the model's top 50 by value per block (with ConnectedSolutions).

| Region | Overlap with size top 50, all candidates | Overlap, scored sites only | Size top 50 not scored: utility | Size top 50 not scored: kwh | Size top 50 not scored: peak |
|---|---|---|---|---|---|
| Metro South | 20 | 23 | 0 | 5 | 6 |
| Worcester | 21 | 22 | 4 | 2 | 1 |

Not scored means the funnel dropped the site (docs/FUNNEL.md): utility is a municipal plant, kwh is under the monthly kWh line, and peak is an estimated peak under 150 kW. A large building is not a good battery site by size alone.
